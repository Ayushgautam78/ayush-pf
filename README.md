# Ayush Gautam - Creative Developer Portfolio

A creative developer portfolio combining classical aesthetics with high-performance modern web engineering.

## Highlights
- **Interactive 3D Hermes Head:** Smooth multi-frame tilt tracking and cursor interaction.
- **Single Celestial Sword System:** Orchestrated scroll unsheathing, section-aware rotation, and cinematic contact gateway zoom.
- **Ecosystem Contributions:** Smooth ticker featuring ecosystem collaborations with a luminous Greek ruins video loop.
- **The Path (Interactive Journey):** Pinned horizontal journey timeline navigation.
- **Modern Aaron Iker Style Badges:** Interactive dual-compartment tech capsules.
- **Stone Linen Color Theme:** Balanced editorial palette with warm stone tones, dark obsidian, and golden accents.

## Tech Stack
- Next.js (App Router)
- React
- TypeScript
- Tailwind CSS
- GSAP & ScrollTrigger

## Getting Started
First, install the dependencies:
```bash
npm install
```

Then, run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
